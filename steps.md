Approved Python-only American CRR delta/gamma estimates use a centered finite difference with h=relative_spot_bump*S (default 0.001*S): delta=[V(S+h)-V(S-h)]/(2h), gamma=[V(S+h)-2V(S)+V(S-h)]/h^2. The same step count is used for all sampled prices. Return value is `(delta, gamma)`, or `None` at expiry/zero volatility. A nonpositive lower spot raises `ValueError`; the estimate does not clamp or switch to one-sided differences. These are finite-tree sensitivities, not analytic Greeks, and can be unstable near exercise boundaries. Bump-size and step-count convergence is not assumed to be monotonic. C++ and pybind11 pricing code remain unchanged; native American Greeks and batch pricing are deferred.
