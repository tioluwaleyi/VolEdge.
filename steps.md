European BSM milestone remains verified: 19 Python tests and 2 CTest checks passed with Python 3.14.4, GCC 15.2, CMake 4.4.4 and pybind11 3.1.0.

American pricing milestone: added `voledge.american.american_crr_price` for American call/put contracts using a Python CRR tree. Conventions approved: standard continuous-yield risk-neutral probability, discount by the continuous rate, compare exercise at every tree date, reject probabilities outside [0,1], and use a deterministic risk-neutral rollback at zero volatility. Expiry returns intrinsic; step count is an integer from 1 to 10,000. Tests cover a one-step hand value, early-exercise put value, American call versus European BSM, boundaries and invalid probabilities/steps. The call comparison uses 2,000 steps and absolute tolerance 0.01; one-step references use 1e-12. Tree errors are not asserted to decrease monotonically. American Greeks, C++ CRR and bindings remain deferred.
